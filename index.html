Recent projects

A mix of projects I picked because they were technically interesting — and because they were actually useful.

01

Coorad

Helped a young startup tighten up its UI structure and smooth out a clunky onboarding flow.

StartupProduct2026

I joined Coorad as an engineer while it was still an early-stage product, working on features that connected users to the platform's core workflows. A lot of my time went into pushing for a more modular UI so the team could ship changes quickly without the product feeling like it was held together with tape. I also took ownership of the onboarding and task flow — the part most likely to lose a first-time user if it's confusing.

That work made the experience feel noticeably more coherent and gave the team a sturdier base to test the product against real users.

02

Face Attendance

A real-time attendance system built on face embeddings, wrapped in an interface simple enough for daily use.

InsightFaceCosine Similarity

This was probably the most technically demanding thing I've built, mainly because it had to recognize people reliably in live conditions instead of just labeling static photos. I used InsightFace embeddings with cosine similarity for fast, accurate matching, then paired that backend with a React and Tailwind front end so it didn't feel like a research demo.

The end result was a lightweight prototype that made a genuine case for turning modern CV tooling into something people would actually use every day.

03

Skin Cancer Classification

An explainable skin-lesion classifier — Grad-CAM heatmaps make its predictions something a person can actually review.

TensorFlowXAI

I built this around a DenseNet121 transfer-learning pipeline, training it on HAM10000 to classify skin lesions. A raw label isn't worth much when the result needs to be reviewed by a person, so I added Grad-CAM heatmaps to show which regions of an image actually influenced the model's decision.

The model landed at 87.78% accuracy, but it was the explainability layer that made it feel like a real prototype rather than just a classification exercise.

04

Khmer Contextual Spell Checker

A spell checker built for Khmer, aimed at context-aware corrections a simple dictionary lookup would miss.

NLPXLM-R

Khmer doesn't have many strong tools for contextual spell correction, especially for everyday writing, so I set out to build one. I combined rule-based candidate generation with XLM-RoBERTa reranking, which let the system catch obvious typos and the trickier, context-dependent mistakes that a dictionary lookup alone would miss.

It reached 75.5% sentence exact-match accuracy — enough to show that a hybrid approach genuinely beats a single-rule baseline for a low-resource language like Khmer.
