02

Face Attendance

Real-time face recognition, not just photo-matching — built on InsightFace embeddings with cosine similarity, fast and accurate enough for live daily use.

InsightFaceCosine Similarity

The hard part wasn't classification — it was making recognition hold up in live, unpredictable conditions instead of clean static photos. I used InsightFace embeddings with cosine similarity for fast, accurate matching, then paired that backend with a React and Tailwind front end so it didn't feel like a research demo.

The end result was a lightweight prototype that made a genuine case for turning modern CV tooling into something people would actually use every day.

03

Skin Cancer Classification

87.78% accuracy skin-lesion classifier (DenseNet121, HAM10000) — with Grad-CAM heatmaps so every prediction is reviewable, not a black box.

TensorFlowXAI

I built this around a DenseNet121 transfer-learning pipeline, training it on HAM10000 to classify skin lesions. A raw label isn't worth much when the result needs to be reviewed by a person, so I added Grad-CAM heatmaps to show which regions of an image actually influenced the model's decision.

The model landed at 87.78% accuracy, but it was the explainability layer that made it feel like a real prototype rather than just a classification exercise.

04

Khmer Contextual Spell Checker

A context-aware spell checker for Khmer — a language with almost no NLP tooling — combining rule-based candidate generation with XLM-RoBERTa reranking. 75.5% sentence exact-match accuracy, beating dictionary-only baselines.

NLPXLM-R

Khmer doesn't have many strong tools for contextual spell correction, especially for everyday writing, so I set out to build one. I combined rule-based candidate generation with XLM-RoBERTa reranking, which let the system catch obvious typos and the trickier, context-dependent mistakes that a dictionary lookup alone would miss.

It reached 75.5% sentence exact-match accuracy — enough to show that a hybrid approach genuinely beats a single-rule baseline for a low-resource language like Khmer.
