02

Face Attendance

I built a real-time face attendance prototype using embeddings and a simple interface for everyday use.

InsightFaceCosine Similarity

One of the most technically interesting systems I built was a real-time face attendance pipeline that had to recognize people reliably under live conditions rather than just classify images offline. I used InsightFace embeddings with cosine similarity for efficient matching and paired that backend with a React and Tailwind interface so the workflow stayed practical for everyday use. The result was a lightweight prototype that showed how modern CV tooling could be turned into a usable attendance workflow.

03

Skin Cancer Classification

I built an explainable skin-lesion classifier with Grad-CAM to make predictions easier to review and trust.

TensorFlowXAI

I built a transfer-learning pipeline around DenseNet121 to classify skin lesions from HAM10000 and improve trust in the predictions by making the model explainable. I added Grad-CAM heatmaps so the system could show which regions influenced each decision, because that matters more than a raw label when a result needs review. The model reached 87.78% accuracy, and the explainability layer made it far more useful as a medical-image prototype.

04

Khmer Contextual Spell Checker

I developed a Khmer spell-checking system for better contextual corrections in low-resource language settings.

NLPXLM-R

I developed a Khmer spell-checking system to address the lack of strong contextual correction tools for Khmer text, especially in everyday writing and low-resource language settings. I combined rule-based candidate generation with XLM-RoBERTa reranking so the system could catch both obvious typos and context-sensitive mistakes rather than relying on simple dictionary matching. The model achieved 75.5% sentence exact-match accuracy, showing that a hybrid approach could outperform a single-rule baseline.
