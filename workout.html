Workout routine

A simple weekly split built around strength, recovery, and consistency. This page exists as a personal reference rather than a public feature.

Sunday — Push
Full session
Chest, shoulders, triceps
Exercise Target Sets x Reps
Barbell or Dumbbell Bench Press Mid/overall chest 4 x 8-10
Incline Dumbbell Press Upper chest 3 x 10-12
Seated Dumbbell Shoulder Press Front/side shoulders 3 x 8-10
Dumbbell Lateral Raise Side shoulders 3 x 12-15
Cable Chest Fly Inner/mid chest 3 x 12-15
Triceps Rope Pushdown Triceps 3 x 12-15
Overhead Dumbbell Triceps Extension Triceps 2 x 12-15
Monday — Pull
Full session
Back, biceps
Exercise Target Sets x Reps
Lat Pulldown or Pull-ups Lats 4 x 8-10
Barbell or Dumbbell Row Mid-back thickness 4 x 8-10
Seated Cable Row Mid-back 3 x 10-12
Face Pull Rear delts + upper back 3 x 12-15
Barbell Curl Biceps 3 x 10-12
Hammer Curl Biceps + forearm 2 x 12-15
Tuesday — Legs
Efficient session
Quads, hamstrings, glutes
Exercise Target Sets x Reps
Barbell Back Squat or Leg Press Quads, glutes 3 x 8-10
Romanian Deadlift Hamstrings, glutes 3 x 8-10
Leg Curl Hamstrings 2 x 12
Standing Calf Raise Calves 3 x 15
Wednesday — Push
Efficient session
Chest, shoulders, triceps
Exercise Target Sets x Reps
Barbell or Dumbbell Bench Press Mid chest 3 x 8-10
Seated Dumbbell Shoulder Press Shoulders 3 x 8-10
Incline Dumbbell Press Upper chest 2 x 12
Dumbbell Lateral Raise Side shoulders 3 x 12-15
Triceps Rope Pushdown Triceps 3 x 12-15
Thursday — Pull
Efficient session
Back, biceps
Exercise Target Sets x Reps
Lat Pulldown or Pull-ups Back width 3 x 8-10
Dumbbell or Barbell Row Back thickness 3 x 8-10
Seated Cable Row Mid-back 2 x 12
Face Pull Rear delts 2 x 15
Barbell or Dumbbell Curl Biceps 3 x 10-12
Friday — Legs
Efficient session
Quads, hamstrings, calves
Exercise Target Sets x Reps
Squat or Leg Press Quads, glutes 3 x 8-10
Romanian Deadlift Hamstrings, glutes 3 x 10
Leg Curl Hamstrings 2 x 12
Calf Raise Calves 3 x 15
Saturday — Full Rest
Recovery day
No gym, no cardio

This is your recovery day and your biggest coding block — let your body fully reset before Sunday’s full push session kicks the week off again.
